Question:
Find the next term: 9, 18, 20, 60, 63, 252, ?.

Options:
A. 255
B. 260
C. 315
D. 256

Correct Option  : D
Correct Answer  : 256

Explanation:
Multiply by 2,3,4,... and then add the same multiplier? 9×2=18; +2=20; ×3=60; +3=63; ×4=252; next +4=256. The paired cycle uses ×n,+n.

D. AB

Correct Option  : B
Correct Answer  : DG
Reference Given : B -> D

Explanation:

QUESTION 35
====================================================================================================

Topic           : Analogy and Classification
Question Number : 281
Question ID     : LR-AC-0281

Question:
Which of the following letter-number terms does not follow the same rule as the other three?

Options:
A. 3F
B. 6B
C. 5C
D. 4D

Correct Option  : A
Correct Answer  : 3F
Reference Given : A -> D

Explanation:
In 6B, 5C and 4D the number equals 8 minus the alphabet position of the letter (8 - 2 = 6, 8 - 3 = 5, 8 - 4 = 4). F is the 6th letter, so 8 - 6 = 2, which means 3F breaks the rule. Hence 3F is the odd one out.
